# Контейнеризация многокомпонентных приложений с помощью Docker Compose
## Вариант 25: Бронирование отелей

### Архитектура (4 сервиса):
1. **Frontend** (Nginx + HTML/JS/CSS) — витрина с карточками отелей, форма бронирования, журнал записей с защитой ПДн и панель управления отелями (`admin.html`).
2. **Backend** (FastAPI) — REST API шлюз для обработки бизнес-логики и связи с базой данных.
3. **Web-service** (FastAPI) — микросервис расчета стоимости проживания по суточному тарифу и датам заезда/выезда.
4. **Database** (PostgreSQL) — СУБД с таблицами `hotels` и `bookings` (с сохранением в volume).

### Функциональные элементы:
- Запрос данных журнала из БД через Backend (Кнопка 1): `GET /api/bookings`
- Расчет стоимости через Web-сервис (Кнопка 2): `POST /api/estimate` -> `POST /calculate`
- Запись бронирования в базу данных: `POST /api/bookings`

### Запуск проекта:
```bash
docker compose up --build -d
```
Веб-сервис доступен по адресу: http://127.0.0.1:8080
